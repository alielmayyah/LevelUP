# LevelUP — Feature List

LevelUP is a gamified, white-label gym member engagement app that turns body composition assessments into a motivating, rewarding journey. Tagline: *Track. Improve. Transform.*

## Status Legend

| Status | Meaning |
|---|---|
| Planned | Not started |
| In Progress | Being built |
| Done | Built, tested, and working with real data |
