Swiss Mono

  • Precise
  • Honest
  • Confident

Gym members don’t need another neon fitness app; they need the scan read to them straight. Swiss Mono sets the verdict as type, lays every value on a measured rule with the normal band marked like a ruler, and keeps colour for one job: cobalt means act or improved. Muscle, fat and water separate by ink weight and pattern, so the body is never coloured good or bad.

Palette

Black ink on white, white on true black. One saturated hue, cobalt, for the primary action, positive change and the active tab. Amber only for “needs attention”, always with black text. Every ratio below is WCAG 2, computed from the hex pair, not estimated. The border token is a decorative hairline; meaning never rides on it.

Type

One stack for both scripts: Archivo sets Latin and every digit (tabular, semi-condensed at 78–80% width for figures, like a dial); Noto Kufi Arabic sets Arabic, a geometric low-contrast Kufi that shares Archivo’s grotesque skeleton. Both checked: Noto Kufi Arabic maps 256 Arabic code points and ships tnum; Archivo ships tnum and a width axis. Arabic gets no tracking and about 10% more leading.

Screens

390 × 844 frames, each carrying its own theme. One focal point per screen: the verdict sentence, the report headline, the trend. One filled button at most.

Components

The ruler is the signature: ticks every 5% of the scale, the normal band bounded by two ink marks, the value as a solid dot. In Arabic the scale runs low on the right. Chips carry a glyph as well as colour.
