Warm Sand

  • Warm
  • Unhurried
  • Grounded

A scan result is personal, so LevelUP should read like a well-made page, not a dashboard. Sand paper and espresso ink keep it calm. One deep green carries every action and every real improvement; saffron only asks for attention. Markazi’s naskh sets the verdict like an editorial line, Rubik’s rounded forms carry the numbers, and each normal range is a sand band you sit inside.

Palette

Each ratio is WCAG 2 contrast, computed from the hex pair: text against the background it sits on, graphics against background (3:1 floor). Fat, stable and the normal band are graphic colors, never body text. Clay appears only in the wordmark and brand illustrations.

Type

Markazi Text, a naskh drawn for Arabic news headlines, gives the verdict the voice of an editorial line; its Latin is a matching book serif. Rubik sets everything else in both scripts, with soft rounded corners and tabular figures for every number. Both load from Google Fonts with real Arabic glyphs. Markazi runs small, so it starts at 21 px and is never used for numbers.

Screens

390 × 844 frames with the real Karim data. Each frame carries its own theme. Arabic is the default; the body figure faces you and is never mirrored, and Arabic charts run oldest on the right.

Components

The same parts in both themes. Chips always pair color with an icon and a word. The empty state is one of the few places clay may draw.
